#  Global superstore Sales-Aanalysis-Project
Data analysis project using power bi
Global Superstore Sales Analysis | Power BI

📌 Project Overview

The Global Superstore Analysis project focuses on analyzing sales, profit, orders, products, customers, regions, and returns using Microsoft Power BI.
The main objective is to understand business performance, identify sales trends, analyze profitability, and generate meaningful insights to support data-driven decision-making.

🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Analyze sales across different regions and states.
- Understand customer purchasing patterns.
- Evaluate shipping performance and delivery trends.
- Analyze returned orders and their impact on business performance.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning and Transformation

📊 Dashboard Pages

# Page 1: Executive Overview
- Overall sales and profit performance.
- Total orders and key performance indicators (KPIs).
- Sales and profit trends.
# Page 2: Regional Analysis
- Sales performance by region.
- State-wise sales analysis.
- Top 10 performing states.

# Page 3: Sales and Product Analysis
- Category-wise and sub-category-wise sales.
- Product performance.
- Top-performing products.
- Profitability analysis.
# Page 4: Returns and Shipping Analysis
- Returned orders analysis.
- Shipping mode performance.
- Order date and ship date analysis.

# Page 5: Customer Analysis
- Customer-wise sales performance.
- Customer purchasing trends.
- Customer segmentation and analysis.
